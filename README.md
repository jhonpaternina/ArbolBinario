# ArbolBinario
S30 - EA3 Actividad Final - Sistema de Inventario Tree-Stock con Árbol Binario de Búsqueda en Java

## Actividad
Sistema de inventario con Arbol Binario de Búsqueda (BST) en Java.

Gestiona productos por ID, Nombre y Cantidad.

Funciones: Insertar, Buscar por ID, Eliminar, Mostrar InOrden.

## Ejecución
javac Producto.java ArbolInventario.java Main.java
java Main
